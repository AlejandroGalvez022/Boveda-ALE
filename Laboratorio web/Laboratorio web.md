# 🧪 Laboratorio web

Volver al [[Indice]] · Mis **demos y experimentos web** hechos con Claude. Cada uno es un archivo `.html` autónomo (sin dependencias externas): lo abres y funciona.

> [!tip] Cómo ver cada demo
> **🌐 Online** → abre el enlace del artifact (se ve en el navegador, es lo cómodo).
> **📁 Archivo** → el `.html` está guardado aquí, en esta carpeta. Click derecho → abrir con el navegador para verlo en vivo, o úsalo como base para un proyecto real.

## 🖤 Marca y producto (nivel cliente)

### AZOGUE — cromo líquido
Landing de estudio de marca con un **hero de metal fundido en WebGL** (raymarching): reflejos de estudio reales, dispersión de color en los bordes, gira y se deforma al hacer scroll y sigue el ratón. *La marca "AZOGUE" es placeholder — se cambia por el cliente real.*
🌐 https://claude.ai/code/artifact/2cacca06-1f1c-4049-acd9-8811b5e609ac · 📁 [[AZOGUE - cromo liquido.html]]

### NOVA★9 — chaqueta que se infla al bajar
Scrollytelling donde una **chaqueta puffer se monta e infla baffle a baffle** mientras bajas: mangas que entran, cremallera que sube sola, cuello que cae, brillo metálico final. La versión buena y realista.
🌐 https://claude.ai/code/artifact/84857b54-737b-4dc3-83f5-dd0e42a44ae7 · 📁 [[NOVA9 - chaqueta que se infla.html]]

### NOVA★9 Pro — marca de ropa Y2K
Landing de marca de ropa Y2K a tope: tipografía holográfica, cursor magnético, transiciones y acabado premium.
🌐 https://claude.ai/code/artifact/24acb424-391d-4bae-97b7-1ed22f8bcd84 · 📁 [[NOVA9 Pro - marca Y2K.html]]

## 🌀 Arte generativo y técnica (WebGL / física)

### Horizonte — agujero negro
Agujero negro raymarcheado en WebGL con **lente gravitacional** (la luz se curva alrededor). "Aquí, hasta la luz da media vuelta."
🌐 https://claude.ai/code/artifact/140bed79-9dbf-4434-a84d-66fe5ea21725 · 📁 [[Horizonte - agujero negro.html]]

### Physarum — moho vivo
Simulación de **moho mucilaginoso** (Physarum) por agentes: miles de partículas dejan rastro, se difunde y decae → forma redes vivas que reaccionan. "Te está oliendo."
🌐 https://claude.ai/code/artifact/fc8a7d3c-c320-4cf5-b417-7467483c7ecf · 📁 [[Physarum - moho vivo.html]]

### Boliches — física 2D
Motor de **física 2D** casero: colisiones e impulsos entre círculos, para juguetear.
🌐 https://claude.ai/code/artifact/ac66f526-910d-4e54-807d-cb1e849ce30a · 📁 [[Boliches - fisica 2D.html]]
