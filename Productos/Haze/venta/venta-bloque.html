Does it work without Framer?

Yes. The download includes a plain <script>, an ES module and a React component, with setup notes for HTML, React, Next.js, Webflow and WordPress.

Will it slow my site down?

It is one draw call per frame, it stops drawing when nobody can see it, and the pixel density is capped. On very large sections you can lower Quality.

What if the visitor's browser has no WebGL?

They see a CSS gradient in the same motif and colours. Never an empty hero. Visitors who asked their system to reduce motion get a still frame.

Can I use it for client work?

Yes. Single project covers one client site; Unlimited covers as many as you build.

Can I change the colours?

Seven palettes are built in, or pick your own four colours and background — Framer colour styles work too.
